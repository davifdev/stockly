# Tecnologias Utilizadas
### Frontend
* Next.js 14 - Framework React Full Stack
* React 18 - Biblioteca JavaScript Para criação de Interfaces
* TypeScript - Tipos Seguros para JavaScript
* Tailwind CSS - Framework CSS de classes utilitárias 
* shadcn - Biblioteca de Componentes
* React Hook Form - Gerenciamento do Estado do Formulário
* Zod - Validação de Esquemas com TypeScript
* Lucide React - Biblioteca de ícones
* Sonner - Biblioteca para Notificações Toast
* dayjs - Biblioteca de utilitários de data
  
### Backend
* PostgresSQL - Banco de dados Relacional
* PrismaORM - ORM performático
* NeonDB - Plataforma Serverless para Banco de Dados

# Experiência de Densevolvimento
* ESLint - Linting para qualidade do código
* Husky - Git hooks framework
* ts-node - Executar TypeScript no Node.js
